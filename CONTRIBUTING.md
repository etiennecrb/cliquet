# Contributing

Thank you for your interest in Cliquet.

## Issues are welcome

Open an issue for a bug, a question or an idea. Say what you did, what you expected and what happened. For a security problem, don't open an issue: see [SECURITY.md](SECURITY.md).

## Pull requests are closed for now

Cliquet doesn't accept pull requests yet. All of its code has one author, so its copyright stays in one place, and a commercial licence of the server stays possible. Before the first outside pull request is merged, Cliquet will ask contributors to sign a contributor licence agreement, and this page will say how.

Until then, an issue is the way to suggest a change. A short example of the fix in the issue is welcome.

## Working in this repository

[AGENTS.md](AGENTS.md) says how the work is done here, by people and agents alike: the commands, the conventions, the commits and the definition of done.
